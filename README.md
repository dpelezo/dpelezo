### Domingos Pelezo · AI engineer

I build LLM applications that real users depend on, and I check them with tests, not only demos. My work centers on agents, retrieval (RAG), tool use through MCP, and the plumbing that keeps them reliable in production.

**Featured work**

- **Infeeds.ai**: a multi-agent RAG platform I built and launched, using LangGraph, the Claude API and MCP. [Demo video](https://youtu.be/wds9wEQtc5E)
- **[AI Assistant API](https://github.com/dpelezo/AI-Assistant-API)** and **[front end](https://github.com/dpelezo/AI_assistant_frontend)**: a research assistant where a LangGraph agent answers with Claude and searches the web with Exa. Offline test suite in CI, friendly failure modes, and a deep research mode that cites its sources. [Live demo](https://ai-assistant-frontend-beta.vercel.app)

**How I work**

- I write the definition of done before the code: the goal, the constraints, and how it will be checked.
- Quality is tested like code: unit tests that never call a live model, and CI on every pull request.
- I build with AI coding agents. They draft; I make the decisions and verify the output.
